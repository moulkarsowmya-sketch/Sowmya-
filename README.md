# Task 3: SQL for Data Analysis

## Objective
Use SQL to retrieve and analyze structured e-commerce data.

## Tool
SQLite. The SQL script creates a small sample e-commerce database, inserts sample data, and demonstrates the required SQL concepts.

## Files
- `Task3_SQL_Queries.sql` — database setup, sample records, analysis queries, view, and indexes.
- `SQL_Interview_Questions.docx` — short answers to the interview questions in the task sheet.
- `sample_query_output.txt` — sample output from selected queries.

## How to run
1. Install the free **DB Browser for SQLite** or use the `sqlite3` command-line tool.
2. Open a new SQLite database.
3. Open `Task3_SQL_Queries.sql` in the SQL editor.
4. Execute the script. Run the SELECT statements to view their results.
5. Save screenshots of the query results from your own SQL application for submission.

## Concepts covered
- SELECT, WHERE, ORDER BY, GROUP BY and HAVING
- INNER JOIN, LEFT JOIN and RIGHT JOIN
- Subqueries
- SUM, AVG and revenue calculations
- Creating and querying a VIEW
- Creating indexes and checking a query plan

## Dataset note
This submission uses a small sample dataset created for demonstration. It is not the external Ecommerce_SQL_Database dataset. You can replace the sample records with another dataset if your internship requires a specific one.
