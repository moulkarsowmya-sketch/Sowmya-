# Task 5 — Exploratory Data Analysis (EDA)

## Included files
- `Task5_Exploratory_Data_Analysis.ipynb` — notebook containing EDA code.
- `Task5_EDA_Report.pdf` — report with charts, observations and findings.
- `employee_attrition_eda_dataset.csv` — dataset used in the notebook.
- PNG files — chart images used in the report.

## Dataset note
This is a synthetic employee attrition dataset created for learning. It is not real employee data.

## Run the notebook
1. Keep the notebook and CSV in the same folder.
2. Install packages: `pip install pandas matplotlib seaborn jupyter`
3. Open the notebook in Jupyter and select Run All.

## EDA topics
`info()`, `describe()`, `value_counts()`, missing values, histograms, boxplots, scatterplots, pairplot and correlation heatmap.
